# Security policy

Report suspected vulnerabilities privately to **info@massive-x.com**, identifying the version/commit, reproduction steps with disposable data, likely impact and a minimal proof of concept. Do not post live secrets or exploit details in public issues. Never include wallet keys, passwords, PINs or funded-wallet files. Support will not request them.

Reports are accepted for the latest public testing release. There is no promised response deadline, independent audit, security certification or bug-bounty payout. Coordinate disclosure after review. Do not access other users’ data, disrupt providers or perform funded tests without their explicit authorization.

See [the release security model](docs/RELEASE_SECURITY.md) and [Android privacy](PRIVACY.md). This project is independent of Massa Labs.
